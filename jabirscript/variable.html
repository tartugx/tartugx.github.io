Variables in JabirScript

Variables allow you to store data values in memory. In JabirScript, variables are declared using the thisIs keyword, combined with the itEquals operator to assign a value.

Declaring a Variable

The standard syntax for setting up a new variable requires naming the identifier right after thisIs, assigning data with itEquals, wrapping text values in &, and ending with ??.

thisIs score itEquals &100&??
thisIs playerName itEquals &Jabir&??

Using Variables

Once a variable is declared, you can easily reference it in other built-in instructions like output commands or conditional checks.

thisIs greeting itEquals &Hello, World!&??
popout: greeting??

Pro Tip: Variable names are case-sensitive and should not include empty spaces to ensure the interpreter parses them correctly.
